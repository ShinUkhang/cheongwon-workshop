const SHEET_URLS = {
  substitute: "선생님의_결보강_시트_CSV_URL",
  homework: "선생님의_수행평가_시트_CSV_URL",
  schedule: "선생님의_학사일정_시트_CSV_URL",
  birthday: "선생님의_생일_시트_CSV_URL",
  notice: "선생님의_공지사항_시트_CSV_URL"  // 선택: P6를 한 경우만 채우세요.
};

[연동하지 않는 것 — 중요!]
- 시간표: 코드에 박아둔 TIMETABLE 그대로 사용해. 시트 연동 금지! (오늘/주간 토글 버튼 반드시 유지)
- 급식: 나이스(NEIS) 급식 API 그대로 사용해. 시트 연동 금지!

[데이터 바인딩]
1. PapaParse CDN(https://cdnjs.cloudflare.com/ajax/libs/PapaParse/5.4.1/papaparse.min.js)으로 CSV를 파싱해줘.
2. 결보강: 오늘 날짜와 일치하는 행이 있으면 상단에 노란 경고 띠로 안내해줘.
3. 수행평가: D-Day·D-1·D-3 뱃지를 달고 마감 임박순으로 정렬해줘.
4. 학사일정: 날짜순 타임라인으로 카드에 바인딩해줘.
5. 생일: 이번 달 생일자만 표시하고, 오늘이 생일인 친구가 있으면 폭죽(Confetti) 효과를 터뜨려줘.
6. 공지사항(선택): notice URL이 있을 때만 — 최신 공지를 첫 화면 팝업으로 띄우고 [오늘 하루 보지 않기] 버튼 추가, 헤더 🔔 버튼으로 지난 공지 목록 보기.
7. 새로고침: 우측 상단 '새로고침 🔄' 버튼으로 시트를 다시 읽어오게 해줘.

[방어 로직 — 필수]
- URL이 비어있거나 "선생님의_" 플레이스홀더면 해당 카드는 샘플(Mock) 데이터를 유지하고 조용히 스킵해. (경고창·에러 화면 금지!)
- CSV 로드 실패(잘못된 URL, 시트 미게시 등)에도 앱이 멈추지 않게 시트별로 try/catch — 하나가 실패해도 나머지 카드는 정상 동작해야 해.
