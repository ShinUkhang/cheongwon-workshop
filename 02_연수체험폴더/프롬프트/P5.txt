안티그래비티, 방금 만든 index.html에 내가 구글 스프레드시트에서 추출한 실시간 CSV 데이터를 연결해줘.

const SHEET_URLS = {
  timetable: "선생님의_시간표_시트_CSV_URL",
  substitute: "선생님의_결보강_시트_CSV_URL",
  homework: "선생님의_수행평가_시트_CSV_URL",
  schedule: "선생님의_학사일정_시트_CSV_URL",
  lunch: "선생님의_급식_시트_CSV_URL",
  birthday: "선생님의_생일_시트_CSV_URL"
};

[데이터 바인딩 세부 로직]
1. PapaParse CDN(https://cdnjs.cloudflare.com/ajax/libs/PapaParse/5.4.1/papaparse.min.js)을 불러와 CSV를 파싱해줘.
2. 시간표 연동: 오늘 요일(월~금)을 자동 감지하여 오늘 요일의 시간표만 1~6교시 순으로 화면에 보여줘.
3. 결보강 연동: 오늘 날짜와 일치하는 행이 있으면 상단에 노란 경고 띠로 안내해줘.
4. 수행평가 D-Day 계산: 오늘 날짜와 마감일을 비교하여 D-Day, D-1, D-3 뱃지를 달고 마감 임박순 정렬해줘.
5. 급식 연동: 오늘 날짜의 급식 메뉴와 칼로리를 카드에 바인딩해줘.
6. 새로고침 버튼: 우측 상단에 '새로고침 🔄' 버튼을 추가해서 누르면 즉시 시트를 다시 읽어오게 해줘.
7. 학사일정 연동: 시트의 학사일정 탭을 날짜순 타임라인으로 카드에 바인딩해줘.
