안티그래비티, 방금 만든 index.html에 구글 스프레드시트를 연결해줘.

const SPREADSHEET_URL = "여기에_구글시트_링크를_통째로_붙여넣기";
// ↑ 시트 주소창 링크를 그대로 넣어줘. ID를 따로 뽑을 필요 없어! ([공유] → "링크가 있는 모든 사용자")

[연동 방식]
- 링크의 /d/ 와 /edit 사이가 스프레드시트 ID야. `SPREADSHEET_URL.match(/\/d\/([a-zA-Z0-9-_]+)/)` 로 뽑아서 `https://docs.google.com/spreadsheets/d/${id}/gviz/tq?tqx=out:csv&sheet=${탭이름}` 형식으로 탭을 직접 읽어줘.
- 연동 탭 5개: 결보강, 수행평가_과제, 학사일정, 생일, 공지사항(선택)
- PapaParse CDN(https://cdnjs.cloudflare.com/ajax/libs/PapaParse/5.4.1/papaparse.min.js)으로 파싱해줘.

[헤더 단어 매칭 — 열 순서를 고정하지 마!]
- 첫 행(헤더)의 단어를 보고 맞는 열을 찾아 연결해줘. (괄호 안은 같은 뜻 다른 표현)
- 결보강: 날짜(일자)·교시·기존과목(원래과목)·변경과목(바뀐과목)·보강교사(담당교사)·수업장소(장소)·학생안내사항(안내)
- 수행평가_과제: 구분·과목명(과목)·제목·마감일(기한)·제출방법(제출)·준비물_세부내용(준비물)·반영비율
- 학사일정: 시작일·종료일·행사명(행사)·대상(대상학년)·상세내용(내용)·준비물
- 생일: 월·일·이름(성명)·축하메시지(메시지) / 공지사항: 제목·내용·게시일(날짜)

[카드 바인딩]
1. 결보강: 오늘 날짜 행이 있으면 상단에 노란 경고 띠로 안내해줘.
2. 수행평가: D-Day·D-1·D-3 뱃지 + 마감 임박순 정렬해줘.
3. 학사일정: 날짜순 타임라인으로 바인딩해줘.
4. 생일: 이번 달 생일자만 표시, 오늘이 생일이면 폭죽(Confetti) 효과를 터뜨려줘.
5. 공지사항(선택): 데이터가 있을 때만 최신 공지 팝업 + [오늘 하루 보지 않기], 헤더 🔔로 지난 공지 목록.
6. 새로고침: 우측 상단 '새로고침 🔄' 버튼으로 시트 다시 읽기.

[연동하지 않는 것] 시간표 = 코드의 TIMETABLE 그대로 (오늘/주간 토글 유지), 급식 = 나이스(NEIS) API 그대로.

[mock 데이터 절대 금지]
- 기존 샘플(mock) 데이터는 전부 삭제! 카드에 가짜 내용이 하나도 보이면 안 돼.
- 탭에 데이터가 없으면 빈칸으로. (예: "등록된 결보강이 없어요 🙂") 링크가 비었거나 잘못되어도 탭별 try/catch — 읽히는 탭만 표시해.
