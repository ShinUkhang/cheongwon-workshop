const SHEET_LINKS = {
  substitute: "결보강_시트_링크", homework: "수행평가_시트_링크", schedule: "학사일정_시트_링크",
  birthday: "생일_시트_링크", notice: "공지사항_시트_링크"  // 선택: P6를 한 경우만 채우세요.
};
// ↑ 각 시트 주소창 링크를 통째로 넣어줘. ([공유] → "링크가 있는 모든 사용자")

[연동 방식]
- 각 링크의 /d/ 와 /edit 사이가 ID야. `url.match(/\/d\/([a-zA-Z0-9-_]+)/)` 로 뽑아내.
- `https://docs.google.com/spreadsheets/d/${id}/gviz/tq?tqx=out:csv` 로 첫 시트를 통째로 읽어줘. (파일마다 시트 1개!)
- PapaParse CDN(https://cdnjs.cloudflare.com/ajax/libs/PapaParse/5.4.1/papaparse.min.js)으로 파싱. 연결 순서: substitute→결보강, homework→수행평가, schedule→학사일정, birthday→생일, notice→공지사항.

[헤더 단어 매칭 — 첫 행의 단어를 보고 열을 찾아 연결해! (괄호 안은 같은 뜻 다른 표현)]
- 결보강: 날짜(일자)·교시·기존과목(원래과목)·변경과목(바뀐과목)·보강교사(담당교사)·수업장소(장소)·학생안내사항(안내)
- 수행평가_과제: 구분·과목명(과목)·제목·마감일(기한)·제출방법(제출)·준비물_세부내용(준비물)·반영비율
- 학사일정: 시작일·종료일·행사명(행사)·대상(대상학년)·상세내용(내용)·준비물
- 생일: 월·일·이름(성명)·축하메시지(메시지) / 공지사항: 제목·내용·게시일(날짜)

[카드 바인딩]
1. 결보강: 오늘 날짜 행이 있으면 상단에 노란 경고 띠로 안내해줘.
2. 수행평가: D-Day·D-1·D-3 뱃지 + 마감 임박순 정렬해줘.
3. 학사일정: 날짜순 타임라인으로 바인딩해줘.
4. 생일: 이번 달 생일자만 표시, 오늘이 생일이면 폭죽(Confetti) 효과를 터뜨려줘.
5. 공지사항(선택): notice 링크가 있을 때만 최신 공지 팝업 + [오늘 하루 보지 않기], 헤더 🔔로 지난 공지 목록.
6. 새로고침: 우측 상단 '새로고침 🔄' 버튼으로 5개 시트 다시 읽기.

[연동하지 않는 것] 시간표 = 코드의 TIMETABLE 그대로 (오늘/주간 토글 유지), 급식 = 나이스(NEIS) API 그대로.

[mock 데이터 절대 금지]
- 기존 샘플(mock) 데이터는 전부 삭제! 카드에 가짜 내용이 하나도 보이면 안 돼.
- 링크가 비었거나 "여기에_" 그대로면 해당 카드는 빈칸으로 조용히 스킵해. (경고창 금지!)
- 시트별 try/catch — 하나가 실패해도 나머지 카드는 정상 동작해야 해.
