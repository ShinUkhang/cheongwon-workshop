안티그래비티, 방금 만든 index.html에 급식 스프레드시트 1개를 연결해줘. (NEIS 조회가 안 될 때 쓰는 백업!)
const SHEET_URL = "여기에 급식 시트 링크 붙여넣기";  // [공유]→"링크가 있는 모든 사용자"로 바꾼 뒤 주소창 링크 통째로
1. 정규식 /\/d\/([a-zA-Z0-9-_]+)/ 로 위 링크에서 시트 ID 추출
2. https://docs.google.com/spreadsheets/d/시트ID/gviz/tq?tqx=out:csv 로 첫 시트를 CSV로 조회 (PapaParse 5.4.1)
3. 첫 행 헤더 단어로 열 매칭 (날짜/요일/메뉴 — 순서 무관)
4. 급식 카드에만 연결. 오늘 날짜 행이 있으면 그 메뉴를 표시하고, 없으면 기존 NEIS API 조회를 그대로 사용해. (시트 우선, NEIS는 백업)
5. 메뉴 뒤 괄호 안 숫자(알레르기 코드)는 빨간색으로 표시해줘.
6. 이 카드의 기존 가짜 데이터 전부 삭제 (mock 절대 금지!) / 시트에도 NEIS에도 없으면 빈 상태 안내 ("오늘 급식 정보가 아직 등록되지 않았어요")
7. try/catch로 감싸고, 우측 상단 '새로고침 🔄' 버튼으로 이 시트 다시 읽기. 다른 카드는 건드리지 마.
