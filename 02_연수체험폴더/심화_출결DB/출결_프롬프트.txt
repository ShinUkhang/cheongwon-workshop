안티그래비티, 대시보드에 '오늘의 출결' 카드를 추가해줘. (심화 도전!)

[준비 1 — 학생명단 시트]
내 구글 시트에 [학생명단] 탭이 있어. 열은 [번호, 이름] 순서야.
아래 상수에 학생명단 CSV URL을 넣어줘:
const ROSTER_URL = "[여기에 학생명단 시트 CSV URL 붙여넣기]";

[준비 2 — 출결 저장용 Apps Script]
아래 Apps Script 웹 앱 URL을 복사해서 [여기에 붙여넣기] 자리에 넣어줘.
const ATTENDANCE_API = "[여기에 Apps Script 웹 앱 URL 붙여넣기]";

[기능 요구조건]
1. 페이지를 열면 ROSTER_URL에서 학생명단(번호·이름)을 불러와 한 줄씩 표시해줘.
2. 각 학생마다 [출석][지각][조퇴][결석] 버튼을 만들어줘. 기본값은 '출석'으로 미리 선택 표시해줘.
3. 카드 상단에 오늘 날짜와 출석/지각/조퇴/결석 인원 요약 뱃지를 보여줘.
4. [출결 저장하기] 버튼을 누르면, 출석이 아닌 학생(지각·조퇴·결석)만 골라서 fetch POST로 {날짜, 번호, 이름, 상태}를 ATTENDANCE_API에 전송해서 구글 시트 '출결기록' 탭에 저장해줘.
5. 저장 전에 "출결을 기록할까요?" 확인창을 한 번 띄워서 실수를 막아줘.
6. 페이지를 열 때는 fetch GET(?date=오늘날짜)으로 오늘 출결을 미리 불러와서 버튼 상태를 표시해줘.
7. 지금 잘 동작하는 기존 카드(시간표·급식 등)는 절대 건드리지 말고 새 카드만 추가해줘.
