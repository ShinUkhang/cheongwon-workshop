안티그래비티, 대시보드에 '오늘의 출결' 카드를 추가해줘. (심화 도전!)

[준비 1 — 학생명단 스프레드시트]
학생명단 전용 스프레드시트를 1개 만들어줘. (탭이 아니라 파일 1개!)
첫 행 헤더: 번호, 이름
아래 상수에 학생명단 스프레드시트 링크를 통째로 넣어줘:
const ROSTER_URL = "[여기에 학생명단 스프레드시트 링크 붙여넣기]";  // [공유]→"링크가 있는 모든 사용자"로 바꾼 뒤 주소창 링크 통째로

[준비 2 — 출결기록 스프레드시트 + Apps Script]
출결기록 전용 스프레드시트를 1개 새로 만들어줘. (학생명단 파일과 별도!)
첫 행 헤더: 기록시간, 날짜, 번호, 이름, 상태, 입력방법, 비고
이 스프레드시트에서 [확장 프로그램] → [Apps Script]를 열어, 이 폴더의 출결DB_AppsScript.gs 코드를 붙여넣고 웹 앱으로 배포해줘.
아래 상수에 배포된 웹 앱 URL을 넣어줘:
const ATTENDANCE_API = "[여기에 Apps Script 웹 앱 URL 붙여넣기]";

[기능 요구조건]
1. 정규식 /\/d\/([a-zA-Z0-9-_]+)/ 로 ROSTER_URL에서 시트 ID를 추출하고,
   https://docs.google.com/spreadsheets/d/시트ID/gviz/tq?tqx=out:csv 로 첫 시트를 CSV로 조회해줘. (PapaParse 5.4.1)
2. 첫 행 헤더 단어로 열을 매칭해줘 (번호/이름 — 순서 무관). 학생을 한 줄씩 표시해줘.
3. 각 학생마다 [출석][지각][조퇴][결석] 버튼을 만들어줘. 기본값은 '출석'으로 미리 선택 표시해줘.
4. 카드 상단에 오늘 날짜와 출석/지각/조퇴/결석 인원 요약 뱃지를 보여줘.
5. [출결 저장하기] 버튼을 누르면, 출석이 아닌 학생(지각·조퇴·결석)만 골라서
   fetch POST로 {날짜, 번호, 이름, 상태}를 ATTENDANCE_API에 전송해줘.
   (Apps Script가 출결기록 스프레드시트에 한 줄씩 저장해.)
6. 저장 전에 "출결을 기록할까요?" 확인창을 한 번 띄워서 실수를 막아줘.
7. 페이지를 열 때는 fetch GET(?date=오늘날짜)으로 오늘 출결을 미리 불러와서 버튼 상태를 표시해줘.
8. try/catch로 감싸고, 실패하면 "출결 시트를 확인해주세요"라고 안내해줘.
9. 지금 잘 동작하는 기존 카드(시간표·급식 등)는 절대 건드리지 말고 새 카드만 추가해줘.
