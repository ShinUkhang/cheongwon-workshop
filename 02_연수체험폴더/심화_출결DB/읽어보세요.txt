============================================================
우리 반 출결 DB 붙이기 — 10분 완성! (심화)
============================================================

출결은 '읽기'가 아니라 '쓰기'가 필요해서 구글 시트만으로는 안 되고,
'Apps Script'라는 작은 프로그램이 통역사로 필요해요.
그래도 3단계면 끝! 코딩을 몰라도 됩니다.

■ 0단계: 시트에 '학생명단' 탭 만들기 (출결 카드의 명단 출처)
  1. 학급 구글 시트를 열고 맨 아래 [+]를 눌러 새 탭을 만드세요.
  2. 탭 이름을 꼭 '학생명단'이라고 지으세요.
  3. 첫 줄에 이렇게 2칸을 적으세요:
     번호 | 이름
  4. 둘째 줄부터 우리 반 학생을 한 줄씩 적으세요. (예: 1 | 김서연)
  5. 이 탭도 [파일] → [공유] → [웹에 게시]에서 CSV로 게시하고 URL을 복사해 두세요.
     (『스프레드시트 템플릿』 엑셀의 학생명단 시트를 복붙하면 빨라요!)

■ 1단계: 시트에 '출결기록' 탭 만들기
  1. 학급 구글 시트를 열고 맨 아래 [+]를 눌러 새 탭을 만드세요.
  2. 탭 이름을 꼭 '출결기록'이라고 지으세요. (한 글자도 틀리면 안 돼요!)
  3. 첫 줄에 이렇게 7칸을 적으세요:
     기록시간 | 날짜 | 번호 | 이름 | 상태 | 입력방법 | 비고

■ 2단계: Apps Script에 코드 붙여넣기
  1. 시트 상단 메뉴 [확장 프로그램] → [Apps Script] 클릭
  2. 왼쪽 Code.gs 파일의 기존 내용을 모두 지우세요.
  3. 이 폴더의 출결DB_AppsScript.gs 파일 내용을 복사 → 붙여넣기
  4. 💾 저장 버튼 클릭 (Ctrl+S)

■ 3단계: 웹 앱으로 배포하기
  1. 오른쪽 위 [배포] → [새 배포] 클릭
  2. 유형 선택에서 [웹 앱] 선택
  3. '액세스 권한이 있는 사용자' → [모든 사용자]로 변경 (★ 이게 핵심!)
  4. [배포] → 권한 검토/허용 → 웹 앱 URL 복사

■ 4단계: 앱에 연결하기
  1. 복사한 URL을 출결_프롬프트.txt의
     [여기에 Apps Script 웹 앱 URL 붙여넣기] 자리에 넣으세요.
  2. 0단계에서 복사한 학생명단 CSV URL도
     [여기에 학생명단 시트 CSV URL 붙여넣기] 자리에 넣으세요.
  3. Antigravity 채팅창에 프롬프트를 붙여넣으면 끝!

[자주 묻는 질문]
Q. '모든 사용자'로 배포하면 아무나 출결을 볼 수 있나요?
A. URL을 아는 사람만 쓸 수 있어요. URL은 반 학생·학부모에게만 공유하세요.

Q. 시트에 직접 적어도 되나요?
A. 네! 앱에서 기록한 것과 시트에 손으로 적은 것이 똑같이 쌓입니다.
   앱을 열면 둘 다 함께 보여줘요.
